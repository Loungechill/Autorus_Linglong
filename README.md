# АвтоРусь — зимние шины Linglong

Исходный фид: https://static.autorus.ru/feeds/arus_linglong.xml

В `feed_winter.xml` остаются только зимние шины, включая нешипованные.
Отбор идёт по названию товара: `Winter`, `зима`/`зимние`, `шип`/`нешип`.
Летние и всесезонные модели исключаются. Неизвестный сезон останавливает
обновление для проверки: предыдущий корректный XML остаётся доступным.

Сохраняются исходные offer ID, categoryId (сейчас 105), категории, названия,
ссылки, цены, остатки/available и остальные поля. XML может отличаться
форматированием, но значения полей не меняются.

При проверке 23.10.2026: 365 товаров в источнике, 261 зимняя шина,
104 исключены. Количество не зафиксировано: новые зимние модели из источника
автоматически попадут в результат, удалённые исчезнут.

## Cloudflare

1. Создайте отдельный Cloudflare Worker
2. Откройте `worker_winter.js` в этом репозитории и скопируйте весь код
3. Замените стандартный код Worker, нажмите Deploy
4. Ссылка для Директа: `https://ИМЯ-WORKER.ВАШ-ПОДДОМЕН.workers.dev/feed.xml`

Worker выдаёт готовый XML из этого публичного репозитория.
Не вставляйте Python-скрипт в Cloudflare.

## Обновления

GitHub Actions → Update winter feed запускается каждые 6 часов
(00:23, 06:23, 12:23, 18:23 UTC / 03:23, 09:23, 15:23, 21:23 Москва).
Планировщик GitHub может запускать задания с задержкой.
Ручной запуск: Actions → Update winter feed → Run workflow.
Кеш выдачи Worker и GitHub может добавить несколько минут задержки.
При ошибке источника новая версия не публикуется, остаётся последняя успешная.
GitHub может отключить расписание публичного репозитория после 60 дней
без активности — в таком случае включите workflow заново в Actions.
